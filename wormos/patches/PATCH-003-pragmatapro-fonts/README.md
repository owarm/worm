# PATCH-003 - PragmataPro fonts

Adds dedicated WORM font families without replacing Android system fonts.

Families:
- worm-pragmata-mono
- worm-pragmata-regular

Local licensed assets:
- PragmataPro_Mono_R_liga_0903.ttf
- Essential PragmataPro-R_1.4.ttf

NOT modified:
- sans-serif
- monospace
- Roboto
- SystemUI
- Settings
- Launcher
- lockscreen

Font binaries are NOT stored in Git.
