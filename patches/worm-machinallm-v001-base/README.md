# worm-machinallm-v001-base

Creates the native Android base for MachinaLLM on Worm OS.

## Scope

- Android environment audit
- Gradle Kotlin project
- Minimal manifest
- Minimal Compose MainActivity
- Material 3
- Android Dynamic Colors
- Debug APK build

## Excluded

- Chat
- Providers
- Services
- Network access
- OpenAI integration
- TermLLM integration
- Database

## Build

```sh
/opt/worm/patches/worm-machinallm-v001-base/build.sh
```

## Debug

```sh
/opt/worm/patches/worm-machinallm-v001-base/debug.sh
```
