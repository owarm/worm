# Worm AI v001

Project:
`/opt/worm/apps/com.worm.ai`

Package:
`com.worm.ai`

Version:
`0.1.0`

Worm AI v001 is a native Android app built with Kotlin, Jetpack Compose, and Material 3.

Worm AI v001 is completely offline and does not communicate with OpenAI.

## Build

```sh
cd /opt/worm/patches/worm-ai-v001
./build.sh
```

## Debug

```sh
./debug.sh
```

## Install

```sh
./install.sh
```

## Uninstall

```sh
./uninstall.sh
```
