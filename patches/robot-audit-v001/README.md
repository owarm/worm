# robot-audit-v001

Audit read-only del dedicated Hetzner Robot per sistema, storage, rete, servizi,
web, porte e layout `/opt/worm`.

Comando:

```sh
/opt/worm/patches/robot-audit-v001/audit.sh
```

Report prodotto:

```text
/opt/worm/logs/audit/robot-audit-20260915-164947.log
```

Timezone richiesta: `Europe/Rome`.

Nessuna modifica automatica applicata a network, routing, firewall, DNS, Caddy,
nginx, systemd, OPNsense, vSwitch o storage.
