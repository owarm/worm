# worm-machinallm-v002-ui

Adds the first local chat UI for MachinaLLM.

## Scope

- Compose chat screen
- Top app bar
- Message list
- Empty state
- Multiline local input
- Local in-memory message state
- Local assistant placeholder response

## Excluded

- Network access
- OpenAI SDK
- OkHttp
- Retrofit
- WebView
- Provider or service integration

## Build

```sh
/opt/worm/patches/worm-machinallm-v002-ui/build.sh
```

## Debug

```sh
/opt/worm/patches/worm-machinallm-v002-ui/debug.sh
```
